这种“反转”题目有一个常见的进阶变体，往往会让候选人措手不及。

题目： 给定一个字符串，要求反转单词的顺序，而不是反转单词内部的字母。

输入："the sky is blue"

输出："blue is sky the"

要求：必须处理掉输入中可能存在的多余空格（首尾空格、单词间多于一个的空格）。

这需要综合运用“整体反转”和“局部反转”的技巧。
